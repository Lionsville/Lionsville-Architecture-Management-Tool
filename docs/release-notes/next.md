# Release notes, next version — draft

*What has landed on `main` since 3.7.3 that a user would notice, in the user's
words. Pasted into the GitHub release when it is cut, and emptied then.*

## The organisation's tree starts folded

- **A home lists the scopes directly under it.** The tree of scopes on the
  organisation screen, and on every domain's home, starts folded: each domain
  is one row that says how many scopes are under it, and its chevron opens it.
  **Show all** above the tree opens every level at once and **Fold all** shuts
  them again. What you open stays open while the app is.
- **The chevron is easier to press.** It is now a target the height of its row
  rather than a 22-pixel caret.

## Search from the organisation's home

- **Search is on every home's bar.** The organisation's home and each
  domain's home have **Search** beside the agent and the menu, and ⌘K opens
  it there as it does inside a scope. It searches the whole organisation —
  that home's scope first — and a hit opens the scope that holds it.

## An agent keeps the tree of scopes

- **An agent can make, rename, describe, move and remove scopes** — from the
  organisation's home or from inside a scope. It makes a domain, or a
  landscape scope with its first board, served by a unit from the start if you
  ask; it gives a scope its type, client and links, and files it under another
  scope with everything below it.
- **A scope with work in it goes only when you say so.** The agent removes one
  scope at a time and never one with scopes under it. Where a scope holds
  work, it tells you what is in it first, and removes it only after you have
  said, in your own words, that it is to go with all of it; a notice on screen
  says what went. There is no ⌘Z for that.
- **The scope you have open stays where it is.** To rename, move or remove the
  scope open in the workspace, or a scope above it, the agent goes to that
  scope's home first, as you would.
- **The domains a unit serves, and a function's, are checked.** An agent that
  names a scope that is not there is told so, and a function is handed only to
  the scopes below the one that defines it.
