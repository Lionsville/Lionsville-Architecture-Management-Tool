# Release notes, next version — draft

*What has landed on `main` since 3.6.3 that a user would notice, in the user's
words. Pasted into the GitHub release when it is cut, and emptied then.*

**Roles and responsibilities stand in an order of your own.** Pick a role on
the operating model's page and press **Move up** or **Move down** in its
inspector to move its column in the Responsibilities matrix. Pick a
responsibility to move it among those of its group, or press ↑ and ↓ on a
group's heading to move the whole group. Each move is one step, and ⌘Z takes
it back. The matrix now opens in this order. **A–Z** is still there, and
**As added** is gone: until you move something, your own order is the order
things were added in. A 3.6.3 desktop reads a folder with the order in it,
but forgets the order when it next saves that folder.

New stable control names: `operating.roleOrder`,
`operating.responsibilityOrder` and `operating.groupOrder`.
