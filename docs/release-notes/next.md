# Release notes, next version — draft

*What has landed on `main` since 3.0.2 that a user would notice, in the user's
words. Pasted into the GitHub release when it is cut, and emptied then.*

- **Three languages: English, Dutch and German.** Frisian is no longer
  offered, in the app or in the manual. If you had chosen it, the app now
  opens in Dutch; nothing else about your settings changes.
- **The desktop app is downloaded from
  [architecture.lionsville.nl/download](https://architecture.lionsville.nl/download).**
  This release, and the ones after it, carry the source, the web build and
  its bill of materials, and no installers. If your copy's update notice
  brought you here, get the newest version from that page; from then on it
  asks before it updates itself, downloads only once you say so, and asks
  you to restart.
- **Get the Desktop App**, under Help in the web build's ⋯ menu, opens that
  page.
