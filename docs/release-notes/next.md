# Release notes, next version — draft

*What has landed on `main` since 3.6.2 that a user would notice, in the user's
words. Pasted into the GitHub release when it is cut, and emptied then.*

**The Responsibilities matrix can be filtered and put in order.** **Roles**
keeps the columns of the roles picked and only the responsibilities any of
them has a part in; **Groups** keeps the groups picked. **A–Z**, now the way
the matrix opens, orders the roles, the groups and the responsibilities by
name; **As added** shows them in the order they were added, as before. The
check column still reads every role, and what is picked stays while you move
between the tabs.

New stable control names: `operating.filterRoles`, `operating.filterGroups`
and `operating.matrixOrder`.
