# Release notes, next version — draft

*What has landed on `main` since 2.1.0 that a user would notice, in the user's
words. Pasted into the GitHub release when it is cut, and emptied then.*

**A container diagram is something you make on purpose.** Double-clicking an
application opens its container diagram; it no longer creates one. Make one
from the right-click menu or from the button on the inspector's General tab,
and it is a step in Activity that ⌘Z takes back. A container diagram can be
renamed, set up and deleted from its entry in the landscape tab's dropdown and
from the chevron after its name — deleting one keeps the application. Back to
landscape returns to the view exactly as you left it.

**The organisation screen explains itself.** One line under the name says
what the screen is and where things live. Every card says what is behind Open.
What the organisation contradicts about itself is one *Needs attention* list
under the cards — a sentence per finding, each a button to the scope and the
record it is about — instead of counts on the cards and red lines on the rows.
A scope's views are *Boards*, and *New board…* offers the same kinds the
editor's + tab does; the children are *Domains and landscapes*. Deleting a
scope says what goes.

**The desktop's menus.** File items that act on an open scope are greyed out
while none is open. The app menu names the product. Edit's Undo, Redo, Delete
and Select All act on the app's own undo stack and on the canvas. Help holds
the User Manual, the keyboard shortcuts and Check for Updates…, on every
platform. *Export Working File…* is now *Save a Copy of the Working File…*.
The native menu is English for now; a channel for the language comes later.

**The badges have one name, one legend, and readable codes.** The feature is
*Operational aspects* everywhere. A legend button beside the lifecycle toggle
lists this board's columns with their codes and long names, the four statuses
and the lifecycle colours; the exported key says the same. A custom column's
code is its initials (*Self-healing* is SH, not SEL). Badge tooltips say the
long name and the status in your language. The inspector's Data tab counts
its aspects instead of showing a dot.

**The palette says how it works.** A caption under Add to canvas, every kind
described in both palette states, the button is Add to canvas, the name field
is labelled, and connection handles say *Drag to connect*.

**Words.** Every finding is a sentence with a subject, a problem and the place
to fix it. *Leverages* is *Uses*, *Realises* is *Delivers*, *answered for by* is
*kept in*, interfaces are *moved*. Tooltips say what a control does. An empty
record links to the page where it is filled in.

**Smaller.** Opening a diagram no longer says *Unsaved changes*. The bar,
the tabs and the documentation toolbar hold at half a screen. The register and
the technology pages open under the bar with the crumbs. The canvas has zoom
buttons of its own, in your language; the align bar appears when two or more
things are selected; the enterprise map says what its dots mean; a board
opened from its home is framed as a whole.
